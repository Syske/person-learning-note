# 个人学习笔记

个人技术学习笔记仓库，涵盖 Java、Python、Go、Linux、Docker、K8s、数据库、前端等多项技术栈。

## 快速开始

```sh
git clone git@github.com:Syske/person-learning-note.git
```

## 目录

完整目录见 [CONTENTS.md](./CONTENTS.md)。

## AI Agent 维护

本仓库支持通过 AI Agent 维护，操作指南见 [AGENTS.md](./AGENTS.md)。

## 笔记分类

| 分类 | 目录 | 说明 |
|------|------|------|
| Java | `java/` | Java SE、JVM、Spring 全家桶 |
| Python | `python/` | Python 基础、FastApi、PyQt 等 |
| Go | `go学习笔记/` | Go 语法、工具类封装 |
| 数据库 | `db/` | MySQL、Oracle、MongoDB |
| Linux | `linux/` | Linux 命令、环境搭建 |
| Docker | `docker/` | Docker、Compose、Harbor |
| K8s | `k8s/` | Kubernetes 相关 |
| 前端 | `web-front/`、`vue/` | HTML/CSS/JS、Vue |
| DevOps | `nginx/`、`tomcat/`、`maven/` | 中间件、构建工具 |
| 工具 | `工具管理/` | 开发工具、效率工具 |
| 更多 | ... | 详见 CONTENTS.md |
