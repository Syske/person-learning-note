## 一、安装（deb 手动解包，无需 debtap）

小鱼易连 Linux 版提供 deb/rpm，分 4 个变体（X86/arm × 统信UOS/麒麟V10）——**Arch 装通用版即可**（包名 `com.xylink.linuxclient`，amd64）。

```bash
# 下载 deb → 解包 → 解压 data.tar.xz 到 /
ar x xylink.deb
sudo tar -xf data.tar.xz -C /
# 结构: /opt/apps/com.xylink.linuxclient/{files,entries}
# 桌面入口: 复制 entries/applications/*.desktop 到 ~/.local/share/applications/ (免 sudo)
```

特点：
- **自带完整 Qt5 库**（libQt5Core/Gui/Widgets 等，零系统依赖缺失）
- 启动脚本 `files/launch.sh`：设 LD_LIBRARY_PATH/QT_PLUGIN_PATH，**强制 `QT_QPA_PLATFORM=xcb`**
- 平台插件**只有 xcb**（无 wayland 插件）
- ⚠️ launch.sh 里 `chmod /opt/apps/@packageName@/` 的 `@packageName@` 是打包模板未替换，chmod 失败无害（可忽略）

## 二、共享屏幕崩溃（Wayland 下）

### 现象
Wayland 会话下打开小鱼易连 → 点「共享屏幕」→ **崩溃**（弹窗消失）。

### 诊断
- coredump：`XYWinQT` **SIGSEGV**
- 调用栈：`MeetingWindow::showShareWidget` → `XYShareSelectionWidget::_refreshCurrentPage` → **`XYShareSelectionCell::setSource` 崩**（枚举屏幕/窗口源）
- 根因：小鱼易连只有 xcb 插件 → Wayland 下跑 **XWayland** → XWayland 下列举屏幕源异常 → 空指针/段错误

### 解决
**切 X11 会话**共享屏幕正常（X11 原生下 xcb 枚举屏幕源正常）：
```
注销 → 登录界面左下角会话 → Plasma (X11) → 登录 → 小鱼易连 → 共享屏幕 ✅
```

## 三、视频会议软件会话要求速查

| 软件 | Wayland | X11 | 备注 |
|---|---|---|---|
| 钉钉 | ✅ | ✅ | 缺库修复后全通（见钉钉投屏修复记录） |
| 小鱼易连 | ❌ 共享崩 | ✅ | 只有 xcb，XWayland 枚举屏幕源崩溃 |
| 企业微信 | ⚠️ 投屏不可用 | ⚠️ | Wine 硬限制，与会话无关 |

**策略**：日常 Wayland；开小鱼易连会议切 X11；钉钉会议不用切。

## 附：faillock 踩坑（sudo 连续失败锁账户）

- PAM 默认 `pam_faillock`：**3 次密码失败锁定 10 分钟**（`/etc/security/faillock.conf` 默认 deny=3, unlock_time=600）
- 现象：连续 sudo 密码输错（或脚本管道没喂对密码）→ 之后**即使密码正确也报 "Sorry, try again"**
- 排查：`faillock --user <user>` 看失败记录
- 解决：等 10 分钟自动解锁；或 root `faillock --user <user> --reset`
- 教训：sudo 自动化脚本务必确保密码正确再试，别连续触发
