## 📸 需要你手动截取的 GUI 图(按顺序)

### 1. Clash Verge 设置界面
- 打开 Clash Verge → **设置 → 系统代理** 或 **设置 → Clash 设置**
- 截取:显示代理绕过列表(`*.syske.local`)的界面
- 保存为 `clash-verge-bypass.png`,替换 Clash 文档中 `> 📸 待补充 GUI 截图` 占位

### 2. BeeCount Web Dashboard
- 浏览器打开 http://192.168.0.103:8869 → 用初始凭据登录(`owner@example.com` / 数据目录 `.initial_admin_password`)
- 截取首页报表(月度趋势/分类占比饼图/热力图)
- 保存为 `beecount-dashboard.png`,替换 Beecount 文档占位

### 3. BeeCount App 服务器设置 + 导入
- App → 设置 → 服务器地址填 `http://192.168.0.103:8869`
- App → 导入 → 选 `count-data_导入BeeCount.csv`
- 分别保存 `beecount-app-server.png`、`beecount-app-import.png`
